# ЕГЕРЬ GPS — план разработки

## Реализовано в исходном прототипе
- Android-проект на Java, открытая карта OpenStreetMap (osmdroid).
- Просмотр и масштабирование карты.
- GPS-позиция по разрешению пользователя.
- Временные путевые точки (не сохраняются).
- Автоматическая сборка отладочного APK через GitHub Actions.

## Ещё не реализовано
- Проверенные границы охотничьих угодий Оренбургской области и Башкортостана.
- Загрузка карт по районам для гарантированной офлайн-работы.
- Сохранение точек и маршрутов.
- Импорт/экспорт GPX.
- Утверждённый дизайн и логотип (исходные файлы пока не загружены).
- Проверка APK на реальном устройстве.

Важно: наличие базовой карты OSM не означает наличия правовых границ охотугодий. До проверки официальных геоданных не отображать фиктивные границы.
